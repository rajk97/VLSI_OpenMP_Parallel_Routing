## 🌟 FUNDAMENTAL C++ BEST PRACTICES (Recall-Based Learning)

### 🔥 **RAII (Resource Acquisition Is Initialization)**
- **Rule**: Every resource acquisition should happen in a constructor, every release in a destructor
- **Application**: Use smart pointers, RAII wrappers for OpenMP locks
- **Example**: `std::unique_ptr`, `std::vector` (auto-manages memory)

### 🔥 **Rule of Zero/Three/Five**
- **Rule of Zero**: If you don't need custom destructor/copy/move, don't define any
- **Rule of Three**: If you need destructor, you probably need copy constructor & copy assignment
- **Rule of Five**: Add move constructor & move assignment for performance
- **Application**: Your `Wire` struct follows Rule of Zero (compiler-generated is sufficient)

### 🔥 **Const Correctness**
- **Rule**: Use `const` everywhere possible - parameters, methods, variables
- **Benefits**: Prevents bugs, enables compiler optimizations, self-documenting code
- **Application**: `const` methods for wire inspection, `const&` for pass-by-reference

### 🔥 **SBRM (Scope-Based Resource Management)**
- **Rule**: Resources tied to scope - automatic cleanup when scope ends
- **Application**: OpenMP critical sections, file handles, memory allocations

### 🔥 **Prefer Stack to Heap**
- **Rule**: Use automatic storage duration when possible
- **Benefits**: Faster allocation, automatic cleanup, better cache locality
- **Application**: Use `std::array` for fixed-size data, `std::vector` for dynamic

### 🔥 **Zero-Cost Abstractions**
- **Rule**: Abstractions should have no runtime overhead
- **Benefits**: Clean code without performance penalty
- **Application**: Templates, inline functions, constexpr for compile-time computation

## Key Concepts

### Problem Domain
- **VLSI Wire Routing**: Route wires between endpoints on a 2D grid using Manhattan-style paths
- **Constraint**: Maximum 2 bends per wire (up to 3 segments)
- **Goal**: Minimize sum-of-squares cost of wire overlaps: `ΣΣ occupancy[i][j]²`
- **Algorithm**: Simplified simulated annealing with probability P for random route selection

## Parallelization Strategies

#### 1. Within-Wires Parallelism (`-m W`)
- **Task**: Parallelize route exploration for individual wires
- **Scope**: For each wire, explore ∆x + ∆y possible routes in parallel
- **Complexity**: Simpler to implement, uniform computation
- **Synchronization**: Read-only access to occupancy matrix during exploration

#### 🔥 **Within-Wires Implementation Best Practices**
```cpp
// ✅ Parallel route exploration with proper data sharing
std::optional<Route> findBestRouteWithinWires(const Wire& wire, 
                                              const OccupancyMatrix& occupancy) {
    const auto routes = enumerateAllRoutes(wire);
    
    Route best_route = routes[0];
    int min_cost = std::numeric_limits<int>::max();
    
    #pragma omp parallel for default(none) \
        shared(routes, occupancy, best_route, min_cost) \
        schedule(static)
    for (size_t i = 0; i < routes.size(); ++i) {
        const int cost = calculateRouteCost(routes[i], occupancy);
        
        #pragma omp critical(best_route_update)
        {
            if (cost < min_cost) {
                min_cost = cost;
                best_route = routes[i];
            }
        }
    }
    
    return best_route;
}
```

#### 2. Across-Wires Parallelism (`-m A`)
- **Task**: Process multiple wires simultaneously
- **Scope**: Route different wires in parallel across threads
- **Complexity**: More challenging due to shared occupancy matrix updates
- **Synchronization**: Critical sections for occupancy matrix modifications
- **Batching**: Process B wires at a time (parameter `-b`), update occupancy after batch completion

#### 🔥 **Across-Wires Implementation Best Practices**
```cpp
// ✅ Thread-safe batch processing
void processWireBatchAcrossWires(std::span<Wire> wire_batch,
                                OccupancyMatrix& occupancy,
                                const int batch_size) {
    // Thread-local storage for route decisions
    thread_local std::vector<std::pair<size_t, Route>> route_updates;
    route_updates.clear();
    route_updates.reserve(batch_size);
    
    // Phase 1: Compute routes (read-only on occupancy)
    #pragma omp parallel for default(none) \
        shared(wire_batch, occupancy, route_updates) \
        schedule(dynamic, 1)
    for (size_t i = 0; i < wire_batch.size(); ++i) {
        auto new_route = findBestRoute(wire_batch[i], occupancy);
        if (new_route.has_value()) {
            #pragma omp critical(route_updates)
            {
                route_updates.emplace_back(i, *new_route);
            }
        }
    }
    
    // Phase 2: Update occupancy matrix (single-threaded)
    for (const auto& [wire_idx, route] : route_updates) {
        updateOccupancyMatrix(occupancy, wire_batch[wire_idx], route);
    }
}
```

```cpp
// ✅ Robust argument parsing with validation
struct ProgramOptions {
    std::string input_file;
    int num_threads = omp_get_max_threads();
    char parallel_mode = 'W';
    double probability = 0.1;
    int iterations = 5;
    int batch_size = 1;
    
    // Validation method
    [[nodiscard]] bool validate() const noexcept {
        return !input_file.empty() && 
               num_threads > 0 && 
               (parallel_mode == 'W' || parallel_mode == 'A') &&
               probability >= 0.0 && probability <= 1.0 &&
               iterations > 0 &&
               batch_size > 0;
    }
};

// ✅ Exception-safe option parsing
std::optional<ProgramOptions> parseCommandLine(int argc, char* argv[]) {
    ProgramOptions opts;
    
    try {
        // Parse arguments with proper error handling
        for (int i = 1; i < argc; i += 2) {
            if (i + 1 >= argc) return std::nullopt;  // Missing value
            
            std::string_view flag = argv[i];
            std::string_view value = argv[i + 1];
            
            if (flag == "-f") opts.input_file = value;
            else if (flag == "-n") opts.num_threads = std::stoi(std::string(value));
            // ... other options
        }
        
        return opts.validate() ? std::make_optional(opts) : std::nullopt;
    }
    catch (const std::exception&) {
        return std::nullopt;  // Invalid numeric conversion
    }
}
```

- `-f`: Input file path
- `-n`: Number of threads (default: OMP_NUM_THREADS)
- `-m`: Parallelization mode (W=within, A=across)
- `-p`: Simulated annealing probability (default: 0.1)
- `-i`: Number of iterations (default: 5)
- `-b`: Batch size for across-wires (default: 1)
